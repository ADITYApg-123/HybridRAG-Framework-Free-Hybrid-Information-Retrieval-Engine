torch.compile Compilation Pipeline and Optimization Modes¶

torch.compile(model=None, *, fullgraph=False, dynamic=None, backend='inductor', mode=None)

Captures Python bytecode into FX graphs via TorchDynamo, traces backward passes with AOTAutograd, and generates fused Triton (GPU) or C++/OpenMP (CPU) kernels via TorchInductor. mode='reduce-overhead' uses CUDA Graphs to minimize launch overhead for small batches; mode='max-autotune' benchmarks Triton matrix multiplication templates and CUDA graphs for peak throughput.

Graph Breaks, Data-Dependent Control Flow, and fullgraph=True¶

When TorchDynamo encounters data-dependent control flow (if tensor.sum() > 0:) or .item() calls, it inserts a graph break, falling back to Python between compiled subgraphs. Passing fullgraph=True raises an error if any graph break occurs. Use torch._dynamo.explain(model)(*inputs) to diagnose graph breaks.
