torch.nn.LSTM Gate Equations and Hidden States¶

class torch.nn.LSTM(input_size, hidden_size, num_layers=1, bias=True, batch_first=False, dropout=0.0, bidirectional=False)

Applies a multi-layer Long Short-Term Memory (LSTM) recurrent neural network. At each timestep t, the cell maintains hidden state h_t and cell state c_t regulated by input gate i_t, forget gate f_t, cell candidate g_t, and output gate o_t. When bidirectional=True, output hidden dimension doubles to 2 * hidden_size. Note: dropout applies between stacked layers except the last layer, so setting dropout > 0 with num_layers=1 triggers a UserWarning and has no effect.

Handling Variable-Length Sequences with pack_padded_sequence¶

To prevent recurrent layers like nn.LSTM from wasting computation over trailing padding tokens, wrap padded batches using torch.nn.utils.rnn.pack_padded_sequence(input, lengths, batch_first=True, enforce_sorted=False) before the LSTM, and unpack outputs back to padded tensors using torch.nn.utils.rnn.pad_packed_sequence.
