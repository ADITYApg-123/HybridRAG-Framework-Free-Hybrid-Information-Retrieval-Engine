torch.inference_mode vs torch.no_grad Context Managers¶

Both torch.no_grad() and torch.inference_mode() disable gradient tracking during forward evaluation. However, torch.inference_mode() is faster because it additionally disables view tracking and version counter bumps on tensors. Tensors created inside an inference_mode block cannot be modified in-place outside the block or used in autograd backward passes.

tensor.detach(), register_full_backward_hook, and Activation Checkpointing¶

tensor.detach() returns a new tensor view sharing storage with the original tensor but detached from the autograd graph (requires_grad=False). To inspect gradients flowing through a module during backpropagation, use module.register_full_backward_hook(hook_fn). To reduce GPU activation memory by recomputing forward activations during backward, use torch.utils.checkpoint.checkpoint(block, *inputs, use_reentrant=False).
