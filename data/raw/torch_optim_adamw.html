torch.optim.AdamW Decoupled Weight Decay vs L2 Regularization¶

class torch.optim.AdamW(params, lr=0.001, betas=(0.9, 0.999), eps=1e-08, weight_decay=0.01, amsgrad=False, fused=None)

Implements AdamW decoupled weight decay regularization. Unlike standard torch.optim.Adam where L2 penalty is added to the gradient before computing adaptive moments m_t and v_t, AdamW subtracts lr * weight_decay * theta_t directly from weights simultaneously with the moment step. Setting fused=True on CUDA launches a single fused multi-tensor kernel update.

Excluding Bias and LayerNorm Parameters from Weight Decay¶

When training Transformers with AdamW, 1D parameters such as bias vectors and LayerNorm / BatchNorm affine scale weights should be excluded from weight decay (weight_decay=0.0) using optimizer parameter group dicts.

optim_groups = [
    {'params': [p for p in model.parameters() if p.dim() >= 2], 'weight_decay': 0.01},
    {'params': [p for p in model.parameters() if p.dim() < 2], 'weight_decay': 0.0},
]
optimizer = torch.optim.AdamW(optim_groups, lr=3e-4, fused=True)
