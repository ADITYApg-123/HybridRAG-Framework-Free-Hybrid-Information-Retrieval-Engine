CUDA Caching Allocator, memory_allocated vs memory_reserved, and empty_cache()¶

PyTorch manages GPU memory via an asynchronous caching allocator. torch.cuda.memory_allocated() returns bytes occupied by active live tensors, whereas torch.cuda.memory_reserved() returns total bytes held by the allocator pool (active plus cached free blocks). torch.cuda.empty_cache() releases unused cached blocks back to the CUDA driver for other processes, but does not free live tensors. Set PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True to mitigate fragmentation OOMs.

Reproducibility: cudnn.benchmark vs torch.use_deterministic_algorithms¶

Setting torch.backends.cudnn.benchmark = True benchmarks and selects the fastest cuDNN convolution kernel for fixed input shapes, but degrades speed when input tensor shapes vary dynamically each step. For strict bit-wise reproducibility, set torch.backends.cudnn.benchmark = False, torch.backends.cudnn.deterministic = True, and call torch.use_deterministic_algorithms(True) with CUBLAS_WORKSPACE_CONFIG=:4096:8.
