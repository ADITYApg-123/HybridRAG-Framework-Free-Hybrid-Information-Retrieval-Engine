torch.nn.CrossEntropyLoss Unnormalized Logits and ignore_index¶

class torch.nn.CrossEntropyLoss(weight=None, ignore_index=-100, reduction='mean', label_smoothing=0.0)

Combines nn.LogSoftmax and nn.NLLLoss in a single numerically stable log-sum-exp pass. Do not apply Softmax before passing inputs to CrossEntropyLoss; pass raw unnormalized logits directly. The parameter ignore_index=-100 masks out padding target tokens so they do not contribute to the gradient.

torch.nn.BCEWithLogitsLoss Numerical Stability and Class Imbalance¶

class torch.nn.BCEWithLogitsLoss(weight=None, reduction='mean', pos_weight=None)

Fuses a Sigmoid layer and binary cross entropy (BCELoss) using the log-sum-exp trick for numerical stability. To handle positive/negative class imbalance in binary classification, set pos_weight to num_negative_samples / num_positive_samples.
