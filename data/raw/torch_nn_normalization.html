torch.nn.BatchNorm2d Running Statistics and Momentum¶

class torch.nn.BatchNorm2d(num_features, eps=1e-05, momentum=0.1, affine=True, track_running_stats=True)

Normalizes 4D inputs (N, C, H, W) per channel across batch and spatial dimensions with default stability constant eps=1e-05. During model.train(), buffers running_mean and running_var update via exponential moving average with momentum=0.1: running_stat_new = (1 - momentum) * running_stat_old + momentum * batch_stat_observed. During model.eval(), running statistics are frozen.

torch.nn.LayerNorm Per-Sample Normalization for Transformers¶

class torch.nn.LayerNorm(normalized_shape, eps=1e-05, elementwise_affine=True, bias=True)

Unlike BatchNorm, LayerNorm computes mean and variance independently per sample across the last D dimensions given by normalized_shape. It maintains no running statistics, behaves identically in train() and eval() modes, and is invariant to batch size for Transformer sequences.
