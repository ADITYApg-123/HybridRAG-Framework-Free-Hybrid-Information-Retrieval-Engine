torch.nn.Conv2d Signature and Parameters¶

class torch.nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0, dilation=1, groups=1, bias=True, padding_mode='zeros')

Applies a 2D convolution over an input signal composed of several input planes. in_channels specifies channels in the input image; out_channels specifies channels produced by the convolution filters. padding='same' pads the input so the output has the same height and width as the input, but padding='same' cannot be used with any stride value other than stride=1. Supported padding_mode values are 'zeros', 'reflect', 'replicate', and 'circular'.

Conv2d Output Spatial Shape Formula and Depthwise Convolution¶

For an input tensor of shape (N, C_in, H_in, W_in), the spatial output height and width of torch.nn.Conv2d are computed using the floor equation: H_out = floor((H_in + 2 * padding[0] - dilation[0] * (kernel_size[0] - 1) - 1) / stride[0] + 1).

When groups == in_channels and out_channels == K * in_channels, this configuration performs a depthwise separable convolution where each input channel is convolved with its own separate set of K filters.

depthwise = nn.Conv2d(32, 32, kernel_size=3, padding=1, groups=32)
pointwise = nn.Conv2d(32, 64, kernel_size=1)
