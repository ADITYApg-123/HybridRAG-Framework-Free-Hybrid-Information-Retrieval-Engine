torch.amp.autocast Precision Casting Rules (FP16 vs BF16)¶

class torch.amp.autocast(device_type, dtype=None, enabled=True, cache_enabled=None)

Runs eligible operations (matmul, conv2d, linear, bmm) in float16 or bfloat16 to reduce GPU VRAM usage and accelerate Tensor Core execution, while keeping reductions and normalization (softmax, LayerNorm, cross_entropy) in float32. Only wrap the forward pass and loss calculation inside with torch.amp.autocast('cuda'):; never wrap loss.backward() inside autocast.

torch.amp.GradScaler Dynamic Loss Scaling and unscale_¶

class torch.amp.GradScaler(device='cuda', init_scale=65536.0, growth_factor=2.0, backoff_factor=0.5, growth_interval=2000)

Prevents small FP16 gradients from underflowing to zero by multiplying the loss by a dynamic scale factor before backward(). Before calling clip_grad_norm_, you must call scaler.unscale_(optimizer) so gradients are clipped at true unscaled magnitudes. If Inf or NaN gradients appear during scaler.step(optimizer), the optimizer update is skipped and the scale multiplies by backoff_factor.
