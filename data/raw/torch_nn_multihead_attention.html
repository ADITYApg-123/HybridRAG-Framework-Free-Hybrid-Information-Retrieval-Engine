torch.nn.MultiheadAttention Overview and Scaled Dot-Product Math¶

class torch.nn.MultiheadAttention(embed_dim, num_heads, dropout=0.0, bias=True, add_bias_kv=False, add_zero_attn=False, kdim=None, vdim=None, batch_first=False)

Computes multi-head scaled dot-product attention: Attention(Q, K, V) = softmax((Q @ K^T) / sqrt(d_k)) @ V. embed_dim must be divisible by num_heads so each head has dimension head_dim = embed_dim // num_heads; otherwise an AssertionError is raised. Setting batch_first=True changes tensor layout from (seq_len, batch, embed_dim) to (batch, seq_len, embed_dim).

MultiheadAttention Mask Semantics: key_padding_mask vs attn_mask¶

In MultiheadAttention.forward, key_padding_mask of shape (N, S) masks padding tokens across the source sequence length S, where a boolean True value indicates the corresponding key position is ignored. attn_mask of shape (L, S) prevents attention to specific positions such as future tokens in causal autoregressive decoding.

When need_weights=False, execution dispatches to the fused torch.nn.functional.scaled_dot_product_attention FlashAttention fast-path kernel.
