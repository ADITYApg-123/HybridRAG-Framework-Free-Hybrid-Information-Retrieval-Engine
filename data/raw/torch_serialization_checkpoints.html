Secure Checkpoint Loading with weights_only=True and map_location¶

torch.load(f, map_location=None, *, weights_only=True, mmap=None)

Passing weights_only=True prevents arbitrary pickle code execution by restricting deserialization to tensors and primitive dicts. Use map_location=torch.device('cpu') when loading GPU checkpoints onto CPU or remapping across distributed ranks, and mmap=True to memory-map large checkpoint files without spiking host RAM.

Handling state_dict strict=False and DDP 'module.' Key Prefix¶

model.load_state_dict(state_dict, strict=False) returns IncompatibleKeys(missing_keys, unexpected_keys) without raising an error when fine-tuning modified heads. Because DistributedDataParallel prepends the prefix 'module.' to all parameter keys, save ddp_model.module.state_dict() for portable checkpoints.
